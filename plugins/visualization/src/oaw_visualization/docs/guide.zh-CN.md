# 数据可视化使用指南

选择**关系图、折线图、柱状图、散点图或分布统计图**卡片。卡片会直接展开大幅详情视图；可以拖动调整尺寸，或打开工作区。关系图的默认比例更接近正方形。

## 连接并选择 schema

在可视化卡片与数据库卡片之间拖线，或在**数据源**中选择数据库。在连接弹窗中先选择 **Schema**，再点击**连接**。取消不会留下连线。

SQL 提供表和视图。MKB 提供结构化 schema 数据集，包括对象数组；关系图还可以读取已发布的知识图谱。没有字段的 schema 需要先补充字段才能绘制。

连接后，在卡片内选择字段：

- **折线图、散点图：** X、数值 Y、可选分组。
- **柱状图：** X 分类、数值 Y、可选 SQL 统计。
- **分布统计图：** 数值；按返回的数据分箱计数。
- **表格关系图：** 起点、终点、可选关系。
- **已发布知识图谱：** 可选实体类型、关系类型筛选。

SQL 可按完整数据表执行计数、求和、平均、最小值和最大值统计；计数不需要 Y 字段。也可以在卡片中切换 Schema，然后重新检查字段。刷新页面后，选择会保留。

## 查看、刷新与恢复

在绘图区内滚轮缩放、拖动平移，双击或点击 **1:1** 复位。键盘支持 `+`、`-`、方向键和 Home；悬停查看数据值。源数据更新后点击**刷新数据**，卡片不会自动轮询。

删除连线会清空图表并停止读取。点击**重新连接**并确认 schema 即可恢复。schema 或字段消失时，会保留原来的名称，直到你主动替换；读取失败可点击**重试**。可视化卡片只读取数据库。

## 理解显示范围

数据上限可选 500、2,000 或 10,000 项。SQL 返回单元格数据还受 1 MiB 大小和三秒查询超时限制。MKB 结构化数据最多读取最近 500 条记录，可继续展开数组；排序仅作用于这批记录。知识图谱的节点、关系分别限制数量。

**部分数据**表示结果被截断。分布统计只统计返回的数据；**全量统计**表示 SQL 在结果条数限制之前对完整表进行聚合。空值或非数值会跳过并显示数量。只保存选择，不把查询结果复制到卡片状态。目前不支持发布到部署工作区。
