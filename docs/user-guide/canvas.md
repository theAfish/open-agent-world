# Cards and connections

## Cards are your workspace

Place cards from the bottom tray. Move and resize them to organize your work; open a card to see its contents and controls. Pan and zoom to navigate a larger world.

| Card | What you use it for |
| --- | --- |
| Agent | Give instructions, choose a model, and use connected tools |
| Text or Image | Keep a brief, reference, or image in the workspace |
| Conversation | Talk with connected Agents and keep the discussion together |
| Sandbox | Work with files and run commands in a separate environment |
| Legion | Organize a team and save a reusable arrangement |

Plugins add more cards, such as task boards and specialized viewers.

## Connections give access

Drag between cards and choose one of the supported relationships. Read the relationship's description before selecting it.

- Let an Agent read a Text card, or allow it to read and edit.
- Connect Agents so they can communicate in the selected direction.
- Connect an Agent to a Sandbox when it needs to inspect files or run commands. Start/stop control is a separate choice.

Moving, grouping, or sticking cards together changes their arrangement. It does not grant access. Removing a connection prevents future access through that relationship.

## Organize a team

A Legion holds a group of cards in a team space. Use its workspace to arrange the team's views, or save the formation for reuse. Resource access still depends on the connections you give the team.

Start with a small working arrangement, then save it once it does what you need.

## Find your cards

**Pack & Card Library** contains installed packs, collected cards, and your decks. A deck selects the cards shown in the bottom tray. Switching decks does not delete cards already on the canvas.

See [Plugins and packs](plugins.md) if a card is missing.
