# Your first team

**Goal:** an Agent reads a short document and discusses it with you in a Conversation. You do not need a Sandbox for this exercise.

## 1. Open a world

On the welcome screen, choose **Start Tutorial** for guidance, or **Start Empty** to follow these steps yourself. If your world already has cards, you can work in an empty area of the canvas.

## 2. Collect three cards

Open **Pack & Card Library**, open **Core essentials**, and add **Text**, **Agent**, and **Conversation** to your active deck. Place one of each on the canvas from the bottom tray.

Opening a pack collects reusable cards. Adding a card to a deck makes it available in the tray. Placing it creates the card you work with.

## 3. Give the Agent something to read

Open the Text card and enter a short brief, for example:

> We are planning a small community workshop. We need an agenda, a preparation checklist, and a short invitation. The event lasts two hours.

Name the card **Workshop brief**. Give the Agent a clear instruction, such as **Help me plan this workshop. Ask before making assumptions.** Select an available model in its settings; [configure one](models.md) if needed.

## 4. Connect the cards

Drag a connection between the Agent and the Text card. Choose the relationship that lets the Agent **read** the document. Choose read and edit only if you want it to change the brief.

Connect the Agent to the Conversation using the available participation relationship. Open the Conversation and select the connected Agent as a participant if needed.

![Connecting cards and choosing a relationship](../assets/demos/connect-cards.gif)

Connections determine what the Agent can use. Placing cards beside one another does not give access.

## 5. Ask for a result

In the Conversation, ask:

> Read the Workshop brief and suggest a two-hour agenda. List any questions you need me to answer.

With a working model connection, the Agent can read the connected document and respond. Check its activity if the request fails; [Troubleshooting](troubleshooting.md) covers common causes.

## Keep going

Edit the brief and ask for a revised plan. Add a second Agent with a different role, or try a Task Board from [Plugins and packs](plugins.md).

Remove a connection when you no longer want to grant that access. This prevents future use through that connection; it does not undo work already completed.
