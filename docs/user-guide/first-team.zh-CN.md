# 第一个 Agent 与资源任务

目标是让 Agent 读取一份简短说明，在 Conversation 中回复。先[连接一个模型](models.md)；不需要启动 Sandbox。

## 1. 进入画布

欢迎页提供 **Start Tutorial（开始教程）**、**Choose a workspace（选择工作空间）** 和 **Start blank（从空白开始）**。本练习选择从空白开始。已有卡片时，在画布空白处继续即可。选择工作空间会放置选中的模板，不会替你向模型发送任务。

## 2. 准备三张卡片

打开 **Pack & Card Library（卡包与卡牌库）→ Packs（卡包）**，开启 **Core essentials（核心基础）**，再点击包装查看已收集的条目。把 **Text file（文本文件）**、**Agent（智能体）**、**Conversation（对话）** 加入同一个牌组，激活该牌组。从底部逐个点击或拖动，放置各一张。

开包把条目加入收藏；加入牌组让它出现在底部；放到画布才会创建实际工作的实例。

## 3. 写任务说明

打开 Text file，将鼠标移到标题上，点击铅笔 **Rename（重命名）**，命名为“活动说明”。输入以下内容，再点击 **Save text（保存文本）**：

> 我们准备举办一场两小时的社区工作坊，需要活动议程、准备清单和一段简短邀请。

打开 Agent 设置，选择已配置的模型，填写职责：“帮我规划这场工作坊。需要假设时，先向我提问。”

## 4. 授予连接权限

从 Agent 边缘的连接点拖到 Text，选择 **Read（读取）** 并确认授权。读取不包含编辑权限。

再连接 Agent 和 Conversation，选择 **Participate（参与）**。打开 Conversation，查看 **Participants（参与者）**。如果其中没有这个 Agent，点击 **Add（添加）**，勾选它，再点击 **Add selected（添加所选）**。点击参与者或用 **@** 提及它，指定消息接收者。

![连接卡片并选择关系](../assets/demos/connect-cards.gif)

卡片相邻、粘合或组成 Legion 都不会自动授予访问权限。

## 5. 发送并核对结果

在 Conversation 中发送：

> 阅读“活动说明”，建议一份两小时的议程，并列出你需要我回答的问题。

会话会显示回复和工具活动。核对它是否使用了说明、是否满足两小时限制。模型仍可能出错，需要你审阅。无法回复时，先检查模型、密钥、服务地址及错误提示；底部 **帮助 → 状态检查** 可以辅助定位。

修改并保存说明，再要求 Agent 调整议程。删除读取连接会撤销此连接提供的后续访问，但不会清除已读信息，也不会撤销已经完成的操作。

接下来阅读[卡片与连接](canvas.md)或[卡包与牌组](plugins.md)。
