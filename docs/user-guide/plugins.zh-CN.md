# 卡包与牌组

卡包提供卡片和工具。安装、收藏、加入牌组、放置到世界是不同步骤。

## 使用已安装卡包

打开 **Pack & Card Library（卡包与卡牌库）→ Packs（卡包）**，开启卡包，再打开包装查看已收集条目。将需要的卡片加入牌组并激活牌组，从底部放置到画布。切换牌组不会删除已放置卡片。

## 从文件安装

选择 **Install Pack from File...（从文件安装卡包）**，打开 `.oawpack`，检查名称、版本、依赖和安装计划，再确认安装。代码卡包可运行受信任的应用代码，只安装你信任的来源。

按界面提示重启。新的纯声明式卡包和内容卡包可能直接激活；Python 代码和已加载版本的升级需要重启。安装成功后仍需开包、加入牌组、放置。

安装状态与运行环境状态不同：某个环境显示使用时准备，不代表整个卡包不可用。遇到错误，按详情中的依赖、冲突或网络提示修复。请求中断时先查看已有安装操作，超时不等于后台已停止。

## 从 Store 获取

**Store（商店）** 连接官方 Marketplace，可搜索、查看详情及版本要求。点击 **Get（获取）** 或 **Update（更新）**，审阅详情和安装计划，再确认。下载后进入同一个安装流程，卡包显示在 Packs 中。

更新需要显式操作，不会后台自动更新。缺少依赖卡包时按提示先安装依赖；Store 不会递归安装所有依赖。Store 不可用时可稍后重试，本地已安装卡包、牌组与世界仍可使用。

## 升级和移除

升级前检查新版本要求。详情中的 **Use this version on restart** 可选择保留的旧版本。移除前先处理世界中的使用和依赖；**Uninstall Pack** 会显示阻碍与资源清理计划。收藏、牌组引用和用户数据保留；源码卡包的卸载不会删除源码目录。

不写代码制作卡片，阅读[卡片工厂](../card-factory.md)。编写完整 Card App，阅读[开发指南](../developers/index.md)。
