# 卡片与连接

## 放置与打开卡片

从底部牌组点击或拖动条目，放置卡片。拖动标题或边框空白处移动；点击卡片打开内容。拖动画布空白处平移，滚轮缩放。选中卡片后按 F 定位，也可以使用适应视图按钮。

| 卡片 | 用途 |
| --- | --- |
| Agent | 设置职责和模型，使用已连接的资源与工具 |
| Text、Image | 保存任务说明或参考资料 |
| Conversation | 与已连接 Agent 对话，保存会话 |
| Sandbox | 在独立环境中操作文件或执行命令 |
| Legion | 组织一组卡片并保存工作区布局 |

## 连接决定权限

从卡片边缘连接点拖到另一张卡片，在出现的选项中阅读并确认关系。读取、编辑、执行和启停是不同权限。关系只在兼容卡片之间提供。

卡片相邻、粘合或放入 Legion 都不等于授权。删除连接撤销此连接的后续权限，已完成操作不会回滚。

Sandbox 需要选择可用运行时和工作目录，再显式启动；只有执行权限时，Agent 不能替你启停它。普通文档阅读不需要 Sandbox。

## 组织团队

按住 Ctrl（Mac 为 ⌘）点击多张卡片，再选择 **Form Legion（组建 Legion）**。原有连接保留。打开 Legion 的 **Workspace mode（工作区模式）**，放置内容、分屏或组合标签页，完成编辑后保存布局。团队模式是额外选项。

切换牌组只改变底部可放置的条目，不会删除画布上的卡片。缺少条目时阅读[卡包与牌组](plugins.md)。
