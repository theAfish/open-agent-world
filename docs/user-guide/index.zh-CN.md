# 使用入门

OAW 用卡片组织智能体、文档和工具。先让一个智能体读一份文档，再根据需要增加协作者和工具；不需要从源码或架构开始学起。

## 第一次使用

1. 在 [下载与安装](../install.md) 中选择适合电脑的安装包。
2. 打开 **Settings → Models**，添加服务连接、API 密钥和准确的模型 ID，选择默认模型并保存。
3. 在欢迎页选择 **Start Tutorial**，或者选择 **Start Empty** 自己操作。
4. 打开 **Pack & Card Library**，开启 **Core essentials** 卡包，把 Text、Agent、Conversation 加入当前牌组，再从底部拖到画布。
5. 在 Text 中写一份简短任务说明；为 Agent 设置职责和模型。
6. 连接 Agent 与 Text，选择读取权限；再将 Agent 连接到 Conversation。在 Conversation 中让它阅读任务说明并给出建议。

卡片放在一起不会自动授予权限，连接时选择的关系才决定允许做什么。这次练习不需要启动 Sandbox。

## 日常操作

- 底部没有卡片：检查是否已开卡包、加入牌组并激活该牌组。
- 智能体不能回复：检查所选模型、连接是否启用以及错误提示。
- 无法读写文档：检查连线与权限，读取权限不包含编辑。
- 想重放教程：点击画布控制区的指南针。
- 想用插件：在已安装卡包中收集卡片；目前 Store 还不是在线插件市场。
