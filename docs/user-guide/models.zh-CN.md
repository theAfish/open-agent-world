# 模型与设置

连接指定模型服务的地址和认证方式，模型条目指定该服务中的模型 ID。普通 Agent 需要可用模型才能回复；插件提供的其他 Agent 可能有自己的配置方式。

## 连接模型

1. 点击齿轮打开 **Settings（设置）→ Models（模型）**。
2. 添加连接，选择服务商或兼容服务地址。
3. 按服务要求填写地址和 API 密钥；本地服务可能不需要密钥。
4. 添加准确的模型 ID 和显示名称。若使用 **Connect AI（连接 AI）** 向导，可先获取服务提供的模型列表，再选择模型；服务不能列举时用手动设置。
5. 选择默认模型并保存设置，再到 Agent 设置中选择这个模型。

模型列表读取成功只说明能访问模型元数据，不代表生成、工具调用或计费已经验证。发送[第一个任务](first-team.md)才能检查真实回复。现有 Agent 可以保留自己的模型选择，修改默认模型不会必然改变它们。

本地服务地址从运行 OAW 后端的电脑访问；托管工作区中的 localhost 不代表你浏览器所在的电脑。

## 更新密钥

输入新密钥会替换原密钥；留空保留已保存的密钥，**Remove saved key** 才会明确删除。设置影响后续请求，正在运行的请求保持其启动时的连接。

## 保留工作

应用数据与安装程序分开存储。**Settings → Storage（存储）** 可以选择新的空目录；保存并按提示重启以完成迁移。需要足够空间复制，旧目录保留作为备份。Sandbox 的工作目录另在 Sandbox 设置中选择。

连接失败时检查服务是否启用、地址、密钥和准确的模型 ID，再读错误提示；不要连续盲目重发。
