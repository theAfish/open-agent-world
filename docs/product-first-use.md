# First task and recovery

For the current welcome screen and a complete exercise, follow
[Your first team](user-guide/first-team.md). This path uses Text, Agent and
Conversation and does not need a Sandbox.

If a request fails, inspect the error and tool activity before sending again.
**Review and resend** copies the earlier message and attachments into the composer
for you to review. It does not automatically repeat tools. A completed external
action may already have taken effect, even when the overall request failed.

Use [Models and settings](user-guide/models.md) for connection problems and
[Troubleshooting](user-guide/troubleshooting.md) for card, installation and runtime
problems. The interactive tutorial can be reopened through **Help → Tutorial**.
