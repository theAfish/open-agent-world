# 卡包工厂（基础版）

卡包工厂是内置 Pack，ID 为 `oaw.factory`。重启后在 **卡牌库 → Packs** 中打开「卡包工厂」，将「卡包工厂工作台」加入卡组并放到画布。工作台包含五台已经连接好的设备；也可以单独放置设备并手动连线。

1. **卡包设计器**：设置 Pack ID、名称、版本、作者、介绍和使用说明，选择四种包装之一及主题色。预览可以点击开合。
2. **卡面设计器**：选择版式和风格，填入语义内容，再选择材质即可保存。需要精细控制时进入高级模式，编辑图层、轮廓、约束与样式令牌。
3. **功能设计器**：配置文本、数值、开关字段及默认值。基础操作支持 `{{name}}` 文本模板、数值求和、数值乘积和按顺序拼接，可在试验台直接测试。卡面设计器可以连入功能设计器，查看各启用视图中已保存的按钮；新工作台已预连此线。自定义按钮的逻辑挂载接口已预留，当前尚不执行自定义逻辑。
4. **卡牌印刷器**：接收一个卡面设计器和一个功能设计器。保存设计后点击「印刷卡牌」，画布上会产生一张独立的卡牌；点击打开即可填写表单并运行。再次修改设计不会改变已印刷的卡。
5. **打包器**：连接一个卡包设计器，将画布卡牌、画布 Legion 或卡组中的 Legion 模板拖入素材区，也可以使用素材选择器加入已保存的 Legion。拖入的是引用，原件保留；导出使用素材的当前配置。移除素材不会删除原件。

通用参数按字段标识匹配，覆盖所有自定义卡牌（包括 Legion 内的自定义卡牌）的字段默认值，不修改原件，也不会覆盖其他插件的任意配置。参数值必须匹配字段类型。

点击「检查卡包」可查看依赖和发布检查；「导出 .oawpack」会重新检查并生成可安装文件。导出后「分享文件」使用系统文件分享；不支持系统分享的浏览器会下载文件。可以将文件发送给朋友或上传到自己的 Release。此版本不包含在线商店发布服务。

接收方从 **卡牌库 → Packs → 从文件安装** 安装并重启。纯印刷卡包会在卡牌库中提供独立卡牌，无需安装作者的工厂设备或代码。其他插件提供的卡牌及 Legion 会保留其原始 Pack 依赖，接收方需要先安装这些依赖。

## 交互式卡面设计

- **卡片**：Hero、Compact、Split、Badge、Editorial、Utility、Minimal、Poster 八种版式使用当前内容生成实时缩略图。可调整信息密度、视觉重心和对齐。风格页提供 Sand、Paper、Ink、Ceramic、Industrial、Playful 六套风格，以及强调色、明暗、柔和程度。
- **内容**：添加图标、标题、副标题、说明、元信息、状态、标签、操作、插图和徽标，内容会自动重排。标题、说明、图标与操作文字跨模式共享，其余槽位按模式保存。插图为内嵌 PNG。点击预览中的元素打开轻量检查器；「转为自由图层」保留当前位置并进入高级模式。
- **材质**：None、Matte、Foil、Holo、Starlight、Iridescent 与强度控制。材质位于文字下方，鼠标移动改变反射；星光为稀疏微小晶点。高级效果可设置整体、边缘或跟随图标/插图的视觉区蒙版，以及精确强度和粗糙度。尊重减少动态效果设置。
- 普通模式的版式、风格和材质选择同步节点、卡片、详细、工作区；工作区自动采用简介与功能分栏。内容槽位仍按视图编排。高级模式中的精确设置只影响当前视图。
- 顶部保留撤销、重做、预览和保存。**润色** 应用确定性的间距、边距、层级、对比度与材质强度修正：普通模式处理四种视图，高级模式仅处理当前视图；显示简短摘要，整体可一步撤销。再次润色不会随机改变设计。
- **高级 → 图层** 中切换节点 / 卡片 / 详细 / 工作区，设置启用、初始显示与打开模式。各模式独立保存设计；关闭模式保留草稿。宽高范围为 96–2048 px，语义槽位随尺寸重排，自由图层按约束缩放。
- **高级 → 约束 / 样式令牌 / 效果** 提供堆叠间距、安全边距、对齐、Fill / Hug / Fixed 宽度与起点 / 居中 / 末端停靠。自由图层的固定宽度与水平停靠会在画布调整尺寸时保留。精确坐标、字号与颜色仅在高级检查器中显示。功能输入字段区域在印刷后绑定功能设计器的字段。
- 拖动默认吸附到 8 px 网格、画布边缘/中心及其他图层的边缘/中心，显示粉色辅助线；按住 Alt 临时关闭。选中画布后可用方向键移动 1 px、Shift + 方向键移动 8 px，Delete 删除，Ctrl/Cmd + Z 撤销、Shift + Ctrl/Cmd + Z 重做。也可使用撤销/重做按钮。
- 在 **编辑形状** 下添加圆角矩形、椭圆、多边形。形状叠放后的并集形成卡面轮廓；每个形状都能移动、缩放、改色、置顶或删除（至少保留一个）。拖动多边形顶点可改变轮廓，也可增加顶点。初始矩形覆盖整张卡，设计异形轮廓时可先添加形状，再删除初始矩形。
- 展开 **背景与 PNG 轮廓** 上传带透明通道的 PNG。开启「以 PNG 透明通道定义形状」时，图片的可见部分决定轮廓，同时用作背景；关闭时，图片作为组合形状内的背景。支持完整显示、填满裁切和拉伸。每种模式最多一张图片，不超过 1 MiB、2048 × 2048 px。
- **添加元素 → 按钮**：在油墨层放置展开、收起、切换视图、删除卡牌、运行或自定义按钮，可重复添加并调整文字、位置、尺寸、字号、颜色、底色和圆角。展开遵循「点击打开」设置，收起遵循通用卡牌的逐级收起规则，切换视图只列出已启用模式。运行按钮使用功能设计器中配置的功能；自定义按钮暂时禁用，等待后续逻辑挂载。
- **成品** 和印刷器会按启用视图提醒缺少的核心操作，仍允许保存和印刷。关闭油墨层、零透明度或完全移出画布的按钮不计作可见操作。请检查异形裁切、遮挡及工艺蒙版后的实际可见性。
- **保存设计 → 印刷卡牌** 后，卡牌使用同一套图层渲染和卡面内按钮，不再附带外部浮动操作栏。旧设计也不会自动补入按钮，可在设计器中添加后重新印刷。设计和 PNG 内嵌在 `.oawpack` 中，安装、Legion 捕获和恢复后均保留，不依赖本地文件路径。

基础形状编辑提供叠放组合与折线多边形，暂不包含贝塞尔曲线、布尔挖孔或逐字段独立排版。印刷卡保持各模式的设计尺寸，要修改尺寸请在设计器调整后重新印刷。连接锚点与画布选中框仍使用卡面的外接矩形。

## 数据与范围

- 设计和打包设置随画布保存。素材本身保留在原画布或模板库中；删除原素材后，打包器会报错，需要移除对应引用或重新加入。
- 默认不导出初始文档、资源和 Legion 共享状态。需要分享时勾选「包含素材中的初始文档、资源与共享状态」。模型选择和机器绑定遵循现有 Legion 可移植规则。
- 最多 20 个表单字段、30 个通用参数、50 份素材；每个 Legion 最多 101 个节点。
- 每种显示模式最多 24 个形状、32 个内容图层；每个多边形最多 24 个顶点。标题等绑定内容区域每种最多一个，自由文本可添加多个。旧卡面配置保留原显示方式；在新设计器保存后会启用交互卡面格式。
- 功能由声明式配置驱动，不执行自定义 Python/JavaScript，也不提供网络请求、条件分支或复杂工作流。复杂能力可以通过已配置的 Legion 一并发布。
- 保持 Pack ID 不变并提高版本号即可发布更新；已安装的同 ID/版本内容不可覆盖，已放置的卡牌也不会随更新被重写。

## 开发契约

`plugins/card_factory` 提供工厂 Pack、设计连线与工作台预设。宿主的 `backend/packs/factory.py` 复用现有捕获锁、模板投影、依赖推导及安装器。

Content Pack 的 schema 2 增加可选 `content.cards`（声明式卡牌 JSON 路径列表）；`content.legions` 可为空，但至少需要一个卡牌或模板。普通单卡快照沿用单节点蓝图。旧的仅 Legion 文件仍然兼容。

卡牌 recipe 包含命名空间 ID、卡面和功能配置，还可选填 `tutorials`，定义[渐进式教程与离线文档](developers/progressive-tutorials.zh-CN.md)。宿主负责注册节点类型和渲染表单；归档仍不接受 Python wheel、JavaScript、未声明文件或安装钩子。卡包工厂设备也可随 Legion 保存，其中打包器的外部素材引用会清空。

交互卡面使用可选 `face.studio` v1，包含 `enabled`、`initial`、`open` 和各模式的 `modes`。每个模式可选 `design` 保存版式、风格、意图控制、令牌覆盖与材质设置，编译成原有 `shapes/elements` 几何；元素的 `placement` 区分语义槽位和自由图层，`overrides` 保存局部样式。打开设计器时重新编译语义槽位，并将未修改的旧默认模板接入当前风格；手工编辑过的旧布局与 PNG 不会自动重排，显式选择版式或润色后才采用自动排版。所有卡面材质均使用克制的反射渲染。形状/内容使用受限的数值坐标与枚举，图片只接受校验过的内嵌 PNG。单个 recipe 的上限为 8 MiB。无 `studio` 的旧 recipe 不会在模型序列化时被加入默认字段，保持旧蓝图配置兼容。
