Source inspected: MatCreator `devel`, commit
`a1a57688cdb7fc476498476cc388f932b6e83d6a`, especially `skill.py`,
`knowledge/{query,kdg_memory,review,synthesizer}.py`, builtin skills and
`SkillGraphController.js`. OAW contracts inspected: SkillPackage, document
actions, containers, capability projection, skill runtime, lifecycle deletion,
artifacts, plugin Window SDK and React Flow world drag handling.

1. Publish coherent Materials Core, Atomistic Simulation, Materials AI and
   Research / Remote Compute packages. Preserve nested families and original
   resources, with explicit OAW execution guidance and source revision.
2. Implement plugin-owned KDG documents with typed validated entries and
   relationships, bounded search/expansion, explicit memory review and resource
   references. Use host persistence and capability authorization.
3. Add the smallest generic document query and atomic resource transformation
   primitives needed. Conversion is explicitly requested and revision checked;
   source consumption, resource retention and target document commit are atomic.
4. Build the plugin Window with progressive graph loading, stable manual layout,
   search/filter/focus, collapsible navigation and an explicit editor/review mode.
5. Demonstrate local ASE structure generation/conversion before and after
   assimilation, using separately authorized Sandbox/Environment resources.
6. Test package integrity, resource preservation, transaction rollback, live
   authorization, graph validation/retrieval and frontend interaction contracts.

Knowledge never grants execution or installs dependencies. Imported publisher
knowledge retains provenance and is not automatically marked verified. The
portable source snapshot remains exportable for future crystallization.
