# Internal records

These files preserve selected investigations, operational receipts and design
constraints that still help maintenance. They are **historical and non-authoritative**,
excluded from the documentation website and bundled Help. Use the
[maintained documentation](../README.md) for current instructions.

Keep a record only when its evidence cannot be replaced by a concise maintained
contract. Do not move obsolete documentation here merely to avoid deleting it;
Git history already preserves removed material. Existing local artifact paths
record where evidence was produced, not files promised in a fresh checkout.

The documentation reset's inventory and validation scope are recorded in
[its internal report](documentation-reset.md).
