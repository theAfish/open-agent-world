# Research Packs

Research tools are ordinary OAW Packs. Install them through the Library/Store,
then open their Pack, add cards to a deck and place them in the World. For a source
checkout, use [the existing setup workflow](docs/developers/setup.md).

| Work | Guide |
| --- | --- |
| Literature and PDF reading | [Library source](plugins/library) |
| Knowledge extraction and experiments | [Knowledge Base](plugins/knowledge_base/README.md) |
| Materials research Agents and tools | [MatCreator](plugins/matcreator/README.md) |
| Atomistic modelling | [AtomSculptor](plugins/atomsculptor/README.md) |
| Structure display | [Structure Viewer](plugins/structure_viewer/README.md) |
| Diffraction matching and fitting | [XRD](plugins/xrd/README.md) |
| SQL data and charts | [SQLite](plugins/sqlite/README.md), [Visualization](plugins/visualization/README.md) |

Model, scientific-runtime and external-service requirements vary by Pack. Check
its guide and installation plan. A successful run or matching score is not by
itself scientific validation. For a configured team example, see the
[Chinese MatCreator walkthrough](docs/user-guide/matcreator-example.zh-CN.md).
