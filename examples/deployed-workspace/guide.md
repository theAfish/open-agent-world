# 欢迎体验部署模式

这是一个已经配置并锁定的 Legion 工作区。你可以直接使用对话与文档，无需了解背后的连接配置。

## 试一试

1. 在左侧新建一个对话，发送「你好，帮我介绍一下这个应用」。
2. 等待演示助手回复。它使用本地预设文本，无需密钥，也不会调用真实模型。
3. 切换右侧的「交付清单」标签。
4. 刷新页面，查看保存的聊天记录；也可以退出后重新登录。

## 这个页面展示什么？

- 发布时选定的对话与文档，以及固定的分栏布局。
- 用户可使用的业务功能。
- 工程配置和连接关系由后台管理，不出现在用户界面。

体验密码：`oaw-demo-2026`。示例仅在本机运行，所有访问者共享同一份业务数据。
